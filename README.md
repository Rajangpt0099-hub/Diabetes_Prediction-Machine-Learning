# 🩺 Diabetes Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on predicting the likelihood of diabetes using Machine Learning techniques. It uses medical diagnostic information to train a classification model that predicts whether a person is likely to have diabetes or not.

The project uses Python and Scikit-learn to build a Decision Tree Classifier and Streamlit to create an interactive web application where users can enter health-related details and receive a model prediction.

## 🎯 Project Objectives

- Build a Machine Learning model for diabetes prediction.
- Understand and explore the diabetes dataset.
- Identify important medical features related to diabetes prediction.
- Train and evaluate a Decision Tree Classifier.
- Save the trained model for future use.
- Develop an interactive application using Streamlit.

## 📊 Dataset Information

The project uses a diabetes dataset containing **768 records and 8 input features**.

### Features Used

| Feature | Description |
|---|---|
| Pregnancies | Number of times pregnant |
| Glucose | Glucose concentration |
| BloodPressure | Diastolic blood pressure |
| SkinThickness | Skin fold thickness |
| Insulin | Insulin level |
| BMI | Body Mass Index |
| DiabetesPedigreeFunction | Diabetes pedigree function |
| Age | Age of the individual |

**Target Variable:**
- `Outcome = 0` – No diabetes predicted
- `Outcome = 1` – Diabetes predicted

## 🤖 Machine Learning Model

This project uses a **Decision Tree Classifier**.

### Model Development Steps

1. Load the diabetes dataset.
2. Separate input features (X) and target variable (y).
3. Split the dataset into training and testing sets.
4. Train the Decision Tree Classifier.
5. Evaluate the model using accuracy score.
6. Save the trained model using Joblib.
7. Use the saved model in the Streamlit application.

## 📈 Model Evaluation

The model is evaluated using the accuracy score on the testing dataset.

The accuracy may vary depending on the training and testing data split.

## 🌐 Streamlit Web Application

The project includes an interactive Streamlit application that allows users to:

- Enter medical information through interactive input controls.
- Submit input values for prediction.
- View the predicted diabetes outcome.
- View prediction probabilities.
- Explore the prediction results through a simple interface.

## 🚀 Installation & Usage

### 1. Clone the Repository

```bash
git clone https://github.com/Rajangpt0099-hub/Diabetes_Prediction-Machine-Learning.git
```

### 2. Navigate to the Project Folder

```bash
cd Diabetes_Prediction-Machine-Learning
```

### 3. Install Required Libraries

```bash
pip install pandas numpy scikit-learn joblib streamlit
```

### 4. Run the Streamlit Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to use the application.
